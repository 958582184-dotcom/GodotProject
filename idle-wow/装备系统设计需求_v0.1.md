# 装备系统设计需求 v0.1

> 状态：草案（待评审）  
> 适用范围：武器 / 防具 / 饰品 的掉落、属性生成、流派构筑  
> 一句话：**固定底材 + 品阶决定词条条数 + 随机词条**，让「控制 / 吸血 / 攻速」三条流派都有明确、可追求的装备成长线。

---

## 1. 设计目标

1. **类型决定下限**：同类型装备的固定属性种类永远一致，玩家换装备时不会「看不懂这件是什么」。
2. **品阶决定上限**：品阶越高，随机词条条数越多，毕业空间越大。
3. **随机决定方向**：额外词条从池中随机抽取，同一件底材可以长出完全不同的流派。
4. **三流派可成型**：控制、吸血、攻速都能仅靠装备词条达到「可玩 → 毕业」的阈值，不依赖某一部位。
5. **随机有保底**：不允许出现「高品阶但零可用词条」的废件，洗练/重铸提供确定性出口。

**非目标（v0.1 不做）**：套装效果、传奇专属特效、装备交易、强化等级、词条继承。

---

## 2. 术语与假设

| 术语 | 定义 |
|---|---|
| 装备类型 | 武器 / 防具 / 饰品 及其子类（单手剑、胸甲、戒指……） |
| 装备等级 | 决定固定属性与平值词条的数值大小（1–60） |
| 品阶 | 普通 / 精良 / 稀有 / 史诗 / 传说 / 神话，决定词条条数与词条强度 |
| 固定属性 | 由装备类型写死种类的属性，不随机 |
| 随机词条 | 品阶带来的额外属性，种类与数值均随机 |
| 词条族 | 通用 / 生存 / 控制 / 吸血 / 攻速 / 暴击 |
| 流派倾向 | 掉落时确定的隐藏标签，只影响抽词条权重，不直接加属性 |

> **假设 A1**：需求里的「级别」按**品阶（稀有度）**实现——条数由品阶驱动，数值由装备等级驱动。  
> 如果「级别」必须指装备等级段，见附录 B 的替代表，二者只能选一套。

## 3. 装备结构

```
装备 = 底材(类型 + 装备等级)
     + 品阶
     + 固定属性（种类固定，数值成长）
     + N 条随机词条（N 由品阶决定）
     + [可选] 流派倾向（影响抽取权重）
```

示例：50 级史诗单手剑 = 固定攻击力 320 + 3 条随机词条（攻速 +9%、普攻吸血 +5%、控制强度 +8%）。

---

## 4. 固定属性

**规则**：属性种类只由装备类型决定，任何品阶、任何等级都不会改变；数值按 `基础值 × 等级系数 × 品阶系数` 成长。

- 等级系数：`1 + 0.04 × (装备等级 - 1)`（60 级为 3.36）
- 品阶系数：普通 1.00 / 精良 1.10 / 稀有 1.20 / 史诗 1.35 / 传说 1.50 / 神话 1.70

### 4.1 武器

| 子类 | 固定属性 | 基础值 | 特性 |
|---|---|---|---|
| 单手剑 | 攻击力 | 80 | 基准武器，攻速 1.00 |
| 单手斧/锤 | 攻击力 | 88 | 攻速 -10% |
| 匕首 | 攻击力 + 攻速 | 64 / +10% | 攻速流底材 |
| 双手剑/斧 | 攻击力 | 104 | 攻速 -20%，可双持惩罚 |
| 长枪 | 攻击力 + 控制强度 | 84 / +5% | 控制流底材 |
| 弓 | 攻击力 + 暴击率 | 80 / +5% | 攻速流远程 |
| 法杖 | 攻击力 + 技能强度 | 72 / +10% | 吸血/控制法系 |

### 4.2 防具

| 子类 | 固定属性 | 基础值 |
|---|---|---|
| 头盔 | 防御 + 生命 | 18 / 70 |
| 胸甲 | 防御 + 生命 | 30 / 120 |
| 护腿 | 防御 + 生命 | 24 / 95 |
| 战靴 | 防御 + 移速 | 15 / +5% |
| 护手 | 防御 + 攻速 | 15 / +5% |

### 4.3 饰品

| 子类 | 固定属性 | 基础值 |
|---|---|---|
| 项链 | 暴击率 + 控制抗性 | +4% / +4% |
| 戒指 | 攻击力 + 生命 | 20 / 60 |
| 护符 | 生命 + 全元素抗性 | 90 / +4% |

> 固定属性中的**百分比**不随装备等级成长，只随品阶系数微调；**平值**随等级成长。

## 5. 品阶与随机词条条数

| 品阶 | 词条条数 | 词条强度系数 | 掉落权重 | 分解价值 |
|---|---|---|---|---|
| 普通 | 0 | 1.00 | 50.0% | 1 |
| 精良 | 1 | 1.05 | 30.0% | 3 |
| 稀有 | 2 | 1.12 | 13.0% | 8 |
| 史诗 | 3 | 1.20 | 5.0% | 20 |
| 传说 | 4 | 1.30 | 1.8% | 50 |
| 神话 | 5 | 1.45 | 0.2% | 150 |

**规则**

- R1：词条条数**只由品阶决定**，与装备类型、装备等级无关。
- R2：同一条词条在同一件装备上**最多出现一次**。
- R3：词条数值 = `基础区间 × 品阶强度系数`，再乘以「完美度」（0–100%，均匀分布）。
- R4：百分比类词条不随装备等级膨胀；平值类词条乘以等级系数。
- R5：词条最终值受第 9 章的全身上限约束，超限时截断，不重抽。

### 6.3 流派倾向

掉落时按以下概率给装备打一个隐藏倾向：

| 倾向 | 概率 | 效果 |
|---|---|---|
| 无 | 55% | 全族按基础权重抽取 |
| 控制 | 15% | 控制族权重 ×3 |
| 吸血 | 15% | 吸血族权重 ×3 |
| 攻速 | 15% | 攻速族权重 ×3 |

倾向只改权重，**不保证**出对应词条（保底规则见 7.3）。

## 7. 随机生成算法

### 7.1 流程

```
输入：装备类型、装备等级、品阶、倾向
1. 由品阶查表得到词条条数 N
2. 计算固定属性
3. 重复 N 次：
   a. 依据倾向加权选词条族
   b. 在族内等权选一条未出现、且不违反互斥组的词条
   c. 在区间内均匀取完美度，乘品阶系数得到数值
   d. 平值词条再乘等级系数
4. 应用全身上限截断
5. 输出装备实例
```

### 7.2 重抽保护

- 单次抽取最多重试 20 次；20 次仍无合法词条时，从「通用」族中补一条未出现的词条。
- 不允许因随机失败产生「少于品阶规定条数」的装备。

### 7.3 保底

| 品阶 | 保底规则 |
|---|---|
| 稀有 | 若有倾向，至少 1 条词条属于该倾向族 |
| 史诗 | 至少 1 条倾向族词条；若倾向为「无」，至少 1 条非通用词条 |
| 传说 | 至少 2 条非通用词条，且其中 1 条为倾向族 |
| 神话 | 至少 3 条非通用词条，且其中 1 条为倾向族 |

### 7.4 伪代码

```ts
function rollAffixes(item, rng) {
  const n = AFFIX_COUNT[item.quality];
  const picked = [];
  for (let i = 0; i < n; i++) {
    const family = weightedPick(familyWeights(item.tendency), rng);
    const affix = weightedPick(
      POOL[family].filter(a => legal(a, picked)),
      rng
    );
    picked.push({ id: affix.id, value: rollValue(affix, item, rng) });
  }
  applyPity(item, picked, rng);
  return picked.map(clampToGlobalCap);
}
```

## 8. 三流派装备目标

### 8.1 控制流

| 项 | 内容 |
|---|---|
| 核心词条 | 控制命中、控制强度、控制时长、控制穿透 |
| 次要词条 | 技能急速、生命、受控减伤 |
| 底材优先 | 长枪 / 法杖；重甲部位 |
| 毕业阈值 | 控制命中 ≥ 35%，控制强度 ≥ 40%，控制时长 ≥ +0.8s |
| 毕业示例 | 5 条中 3 条控制族，1 条技能急速，1 条生命 |

### 8.2 吸血流

| 项 | 内容 |
|---|---|
| 核心词条 | 普攻吸血 / 技能吸血、击杀回复、过量转盾、低血增吸 |
| 次要词条 | 生命、攻击力、攻速（提高触发频率） |
| 底材优先 | 匕首 / 法杖；护符、戒指 |
| 毕业阈值 | 总吸血 15–25%，击杀回复 ≥ 3%，过量转盾 ≥ 10% |
| 风险控制 | 总吸血硬上限 30%，对护盾目标吸血减半 |

### 8.3 攻速流

| 项 | 内容 |
|---|---|
| 核心词条 | 攻击速度、连击几率、暴击率、暴击伤害 |
| 次要词条 | 移动速度、攻击力、普攻吸血 |
| 底材优先 | 匕首 / 弓；战靴、护手 |
| 毕业阈值 | 攻速 +90%～+130%，暴击率 ≥ 40%，连击 ≥ 12% |
| 风险控制 | 攻击间隔下限 0.25s，攻速总加成上限 +150% |

> 三流派的关键词条**分散在不同部位**，不允许单件装备同时提供两条以上同族核心词条（见 9.4）。

## 9. 平衡约束

### 9.1 控制递减（对同一目标）

| 10 秒内第 N 次受控 | 效果 |
|---|---|
| 1 | 100% |
| 2 | 75% |
| 3 | 50% |
| 4 | 25% |
| 5+ | 免疫 5 秒 |

- 单次控制时长上限：PvE 5s / PvP 3s。
- 控制命中与控制抗性做减法，最低命中率 15%，最高 85%。

### 9.2 吸血

- 全来源总吸血上限 **30%**；超过部分转化为等量「治疗加成」但不超过 10%。
- 对护盾造成的伤害不吸血；过量治疗转盾上限 = 最大生命 15%。
- PvP 中吸血效果 ×50%。

### 9.3 攻速

- `实际攻击间隔 = 基础间隔 / (1 + 攻速加成)`，下限 **0.25s**。
- 攻速加成全身上限 **+150%**；达到上限后多余攻速按 1:0.5 转为攻击力。

### 9.4 词条分布约束

- 单件装备同族词条最多 2 条（神话最多 3 条）。
- 同一互斥组只能出现 1 条。
- 神话装备不允许 5 条全部同族。

### 9.5 随机保护

- 连续 10 次掉落未出史诗及以上，下一次必出史诗（保底计数跨场景保留）。
- 洗练：可锁定 1 条词条重 roll 其余，消耗递增；洗练 10 次必出至少 1 条非通用词条。
- 分解：按品阶返还材料，传说/神话额外返还 1 个「定向重铸」道具。

## 11. 验收标准

1. **类型固定性**：任意 1000 件「单手剑」，固定属性种类 100% 为「攻击力」。
2. **条数正确性**：各品阶产出的词条数严格等于 5 章表格，误差 0。
3. **不重复**：任意装备的词条 id 无重复。
4. **互斥生效**：任意装备不出现同一互斥组的 2 条词条。
5. **数值区间**：所有词条数值落在 `区间 × 品阶系数 × [0,1]` 内。
6. **等级成长**：同品阶下，装备等级越高，平值词条期望值单调递增。
7. **保底生效**：稀有及以上 100% 满足 7.3 的保底规则。
8. **上限生效**：构造超限装备时，最终面板不超过 9.2/9.3 的上限。
9. **流派可达**：各流派毕业配装可通过正常掉落 + 洗练在预期时长内达成（模拟验证）。
10. **分布合理**：10 万次模拟中，各词条族出现频率与 6.1 权重偏差 ≤ 2%。

## 13. 待确认问题

1. 「级别」到底指品阶还是装备等级段？两者只能选一个驱动条数。
2. 是否 PvP / PvE 分套数值？（当前按统一数值 + PvP 系数处理）
3. 装备是否绑定？能否交易？影响保底与工作室收益。
4. 是否需要套装 / 传奇特效？会改变词条条数的设计空间。
5. 伤害公式基准未定，固定攻击力的绝对值需在公式确定后统一校准。
6. 洗练锁词条是否收费？收费方式影响「随机保护」的强度。
